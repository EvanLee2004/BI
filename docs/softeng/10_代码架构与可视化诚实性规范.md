# 经营罗盘代码架构与可视化诚实性规范

> **项目补充正本**：先遵守工作区 `AI开发规范/软件工程规范/代码架构与整洁度强制规范.md`，再遵守本文。
> **架构终态**：数据源 → ingest/db → profit/domain → viewmodels → `/api/v1/*` → Vue。导出复用同一 VM/snapshot 语义。
> **禁止**：新建平行计算链、复制 VM 类型、在 Vue 重算金额/档位、用视觉归一化伪装金额比较、只凭 health 200 判定发布成功。

## 1. 后端职责与目录

| 层 | 可以做 | 不可以做 |
|---|---|---|
| `src/ingest/` | 抓取、清洗、校验、入库 | 利润/档位/页面展示 |
| `src/db/` | SQL、事务、查询、写入 | 页面显示串、业务排序 |
| `src/profit/` | 财务口径与金额计算 | HTTP、Vue 字段拼装 |
| `src/domain/` | 业务规则、分类、阈值、趋势语义 | HTML/CSS、请求对象 |
| `src/viewmodels/` | 数值+`*_disp`、轴元数据、可见状态 | 重做财务公式、访问数据库 |
| `src/routes/` | 鉴权、参数校验、调用、响应 | 大段业务计算、重复 SQL |
| `src/server.py`/factory | 装配 | 业务 handler |

### 后端整洁门闩

1. `src/viewmodels/packers.py` 只保留公共门面和小型通用 packer；一个业务板块超过约 200 行，迁到 `viewmodels/<feature>.py`。
2. 一个 domain 能力一个子包；公开函数经 `__init__.py` 明确导出，禁止复制实现过渡。
3. Route 业务函数圈复杂度 ≤10；C901 豁免只用于纯注册/分发壳。
4. 金额全程整数分；图表可绘制值由后端下发确定单位的数值字段，前端不得从 `*_disp` 反解。
5. 缺失数据不转 0；`actual|forecast|incomplete|missing` 等状态必须显式进入 VM。

## 2. 前端三层的准确解释

原有三层继续有效，但“Layer 3 只组装”必须落到可审查结构：

```text
tokens.css
  ↓
components/base/（纯展示基座）
  ↓
feature 容器 + feature 子组件
       ↘ composables/（交互与请求状态）
       ↘ charts/（纯 option builder）
       ↘ types/vm.ts（唯一 VM 类型）
```

### 强制规则

1. `frontend/src/types/vm.ts` 是 VM TypeScript 唯一正本；业务 `.vue` 禁止重复定义同名/近义 API 类型。
2. Feature 容器只做 store 接入、子组件编排和少量事件连接；不得同时容纳 fetch/cache/filter/sort/compare/chart option/大模板。
3. 请求、缓存、筛选、选择、对比状态进 `composables/use<Feature>.ts`。
4. ECharts option 进 `charts/<feature>Chart.ts` 纯函数；组件只传 VM 与交互参数。
5. 紧耦合子组件统一用 feature 前缀；重点客户目标目录：

```text
frontend/src/components/key-customers/
  KeyCustomersPanel.vue
  KeyCustomersSummary.vue
  KeyCustomersStructure.vue
  KeyCustomersPool.vue
  KeyCustomersInsight.vue
frontend/src/composables/useKeyCustomers.ts
frontend/src/charts/keyCustomersChart.ts
frontend/src/styles/components/KeyCustomersPanel.css
```

6. 本项目看端业务组件禁 `<style>`，继续使用 token + 组件 CSS；管理端保持既有 Element Plus 例外，不借机混用。
7. 业务列表 `:key` 必须用 `mkey` 等稳定键；禁止 index 作为会筛选/排序列表的身份。
8. 拆分不是新建框架：继续 Vue 3 + Pinia + ECharts，不引入新状态库、图表库或 CSS 框架。

### 本轮量化目标（重点客户）

- `KeyCustomersPanel.vue` 降为编排容器，目标 ≤300 行。
- 单个子组件/`useKeyCustomers.ts` 目标 ≤350 行；图表 builder 目标 ≤250 行。
- 若因模板天然长度超过目标，交付报告必须写职责证明；不得为过行数拆成无意义碎片。
- `KeyCustomersPanel.vue` 内 VM 类型定义归零。
- “客户头部、趋势摘要、折线系列、对比标签”必须来自同一选择状态；不得出现头部 A、图上 B/C 的状态撕裂。

## 3. VM 与图表契约

金额趋势的推荐 VM：

```ts
type AmountPoint = {
  month: number
  value_fen: number | null
  value_wan: number | null
  value_disp: string
  status: 'actual' | 'incomplete' | 'missing'
}

type AmountAxis = {
  unit: '万'
  min: 0
  max: number
  interval?: number
  ticks?: number[]
  ticks_disp?: string[]
}
```

### 金额模式（默认）

- 多客户使用**同一 Y 轴**、同一“万”单位、0 基线。
- 2 万与 200 万的峰值高度必须约为 1:100，而不是都等于 100。
- Y 轴可见，标题/副标题明确“月下单金额（万）”。
- tooltip 显示精确值；图上直接标注每条线的峰值和最新非零/非空值。
- 当月未完结用样式+文字说明；未来未发生月份用 null/空点，不得画成实际 0。

### 节奏指数模式（可选）

- 只用于比较季节性形状；各客户自身峰值=100。
- 开关名必须是“节奏指数”，图内固定说明“各客户自身峰值=100，仅比较节奏，不比较金额”。
- 不得默认开启；不得与金额轴共用标题或单位。

### 测试不变量

1. 小客户 2 万、大客户 200 万：金额模式绘图值不相等，比例正确。
2. 节奏模式两者峰值可以同为 100，但标题和说明必须出现。
3. tooltip、直接标签、Y 轴单位三者的金额一致。
4. missing ≠ 0，未来月份不连成零线。
5. 单选、加入对比、移出对比、切池、搜索后，标题/摘要/series 同源。

## 4. 管理层首屏与“有排面”

“霸气”来自信息层级和可信度，不来自继续堆霓虹：

1. 首屏先回答：利润怎么样、与目标/上期差多少、风险在哪里、下一步找谁。
2. 一个主 KPI（税前利润/当前管理层拍板指标）占主视觉；2～3 个副 KPI；其余下沉。
3. 增加确定性“经营结论带”，只能从后端已算字段生成，不接 AI、不编原因。
4. 数据完整性、截至日期、预测/实际在首屏可见；黄/红时明确哪些指标受影响。
5. 重点客户块保留经营池与行动队列；图表服务于“金额规模”和“跟进动作”，不只展示形状。
6. 保留三主题与现有 SciFi 设计语言，但减少全页面同权重描边/荧光；用字号、留白、对比度建立层级。
7. `/` 是老板看数主入口；`/admin` 的嵌入预览只用于管理，不作为领导演示画面标准。

## 5. 发布真实性

`deploy/linux/reload_kanban.sh` 成功必须同时证明：

1. 记录重载前 serve PID/启动时间/运行 marker。
2. 执行 systemd restart 或精确终止目标 serve。
3. 新 PID/启动时间与旧值不同。
4. `/api/v1/health` 200。
5. 运行时 VERSION/commit/build marker 与待发布 commit 一致。
6. 本次新增契约探针成功（例如 VM 新字段存在）。

只满足第 4 项必须返回非 0，不得打印成功。对应行为测试必须能复现“旧进程仍 200”的假绿场景。

## 6. 项目架构守卫

`tests/run_verify.sh` 必须包含：

- VM 类型单源守卫；
- 前端跨层与 `<style>`/token 守卫；
- 变更文件的职责/体量阈值守卫（允许显式、可审计的豁免清单）；
- 金额图表共同尺度与缺失语义测试；
- route/db/domain 依赖方向守卫；
- reload 新进程/新构建真实性测试；
- 既有 32 周期金额回归。

守卫必须做先红后绿证明；仅 grep “某字符串存在”不算业务行为测试。

## 7. 参考依据

- Vue 官方：SFC 按松耦合组件组织，组件单文件、紧耦合子组件用父名前缀、base 组件不碰全局状态。
- FastAPI 官方：大型应用拆成多个模块和 router，主应用只装配。
- Apache ECharts 官方：数值轴承载定量值与单位；`series.label.show` 用于直接显示值；空值与 0 语义不同。
- 工作区事故：3.4.3 每客户峰值各自归一 100，导致 2 万与数百万同高；reload 只查 health 200，旧进程存活时产生假成功。
