# 看板使用手册

> **版本对齐（2026-07-29）**：产品 **v3.3.1**（以根目录 `VERSION` 为准）。统一登录；会话仅 **`kanban_sid`**（须重登后只认此 cookie）；看数 Domain→VM→Vue；KPI 交付金额小字「含税」、副行「不含税 · ÷1.06」。

**这篇解决什么问题**：第一次打开「经营看板」时，知道从哪进、每一屏看什么、怎么换时间段。

> 截图均在本机合成数据环境拍摄（`_golden_data`），**不含真实客户与真实金额**。见 `docs/用户手册/截图/`。

## 1. 怎么打开

**全员只记两个根地址（用自己的账号登录即可；不要记一长串带 `/bu/` 的链接）：**

| 场景 | 地址 |
|------|------|
| **公司办公区（内网）** | `http://192.168.30.46` |
| **公司外 / 手机流量（外网）** | `http://101.254.102.94:8001` |

说明：外网地址在公司 WiFi/有线里**打不开是正常的**，办公区请用内网。关掉浏览器再开、或收藏根地址，业务线账号也会自动进入自己的业务线（2.4.3 已加固）。

1. 用电脑浏览器打开上表对应地址（本机开发试用仍是 `http://本机IP:8018/`）。
2. 进入**同一登录页**，输入账号和密码，点 **进入**（无单独管理员登录页；会话 cookie 仅 **`kanban_sid`**，升级后若进不去请重新登录）。
3. 登录后自动分流：管理员 → 管理后台；整体权限 → 公司看板；业务线 → 自己的业务线页。

## 2. 首页五块在说什么

从上到下通常是：

| 区块 | 你看什么 |
|------|----------|
| **基本情况** | 下单、交付、毛利、税前利润、回款五张卡 |
| **经营利润** | 收入/成本趋势 + 管理利润表（可点「查看构成」） |
| **收入与毛利结构** | 按客户、按销售的排名条 |
| **下单与回款** | 回款图 + 排名 + **重点客户分析**（四区最底） |
| **费用明细** | 上方热力格子图 + 台账明细表（可翻页、筛选）；明细区为**日历起止日期**（按收单日期到日）+「查询 / 本月 / 返回本年」，默认本年全年；「本月」=当月1日～今天；该区间**只影响明细表**（热力/费用折线仍按全年月度）；**默认仅期间费用大类**（与图表口径一致），可勾「显示全部台账记录」看全量；导出跟随当前日期区间与口径 |

![首页](截图/viewer_home.png)

### 2.1 费用热力格子图（怎么看）

- 位置：板块「五 · 费用明细」最上方，标题 **费用热力 · 月份×报表大类**。
- **横轴** = 有数的月份；**纵轴** = 报表大类（与费用趋势同一套分类）。
- **格子颜色深浅** = 该月该大类金额大小（青偏浅 → 金偏深）；**悬停**格子可看金额显示串。
- 数字全部来自后台已算好的显示串，**页面不做加减乘除**。
- 手机窄屏可左右横滚看完整格子。

> 截图证据见 `docs/验收证据/20260719_54p14/live/heatmap.png`（合成/内网环境）。

### 2.2 费用明细表日期与导出

- 工具栏为 **起 / 止** 日历日期（按**收单日期**到日筛选）+ **查询 · 本月 · 返回本年**（顺序固定）。
- **默认** = 本年 1 月 1 日～12 月 31 日；**本月** = 当月 1 日～今天；**返回本年** = 恢复全年。
- 该区间**只改明细表行数/分页**，上方热力格子与费用折线仍按全年月度，不随明细区间联动。
- 「显示全部台账记录」与关键词筛选可与日期区间并存；**导出 Excel** 跟随当前日期区间 + 口径开关，文件内「口径说明」表注明区间与口径。

### 2.3 下单与回款「本月」

- 「按时间段查询」在 **返回默认（年）** 左边有 **本月**：一点即设当月 1 日～今天并查询，只影响本板块排名双卡区间。

### 2.4 重点客户下单分析（3.4.2）

- **位置**：板块「四 · 下单与回款」最底部（排名双卡下面）；标题为 **重点客户下单分析 · {年}**。
- **口径**：按**自然年**「下单预估本币」累计分级，**每年清零**；与顶栏月/季标签无关（切「3月」也不会按 3 月重算等级）。
- **六档**（万）：S≥200 · A 80～200 · B 30～80 · C 10～30 · D 3～10 · E 不足 3（仅当年有下单的客户）。
- **布局（3.4.2）**：**上**两个饼图（各级户数 / 金额结构）→ **中**六档客户名单（满宽）→ **下**连续月下单折线（满宽，够大）。
- **名单**：六档**默认全部展开**；每档名单**限高滚动**，可看全但不撑成长墙；S/A/B 首包即有名单，C/D/E 展开时自动加载。
- **选中**：**默认不预选**任何客户，下方折线为空（提示「点击上方客户查看 1～12 月下单」）；**点客户行**才高亮并画折线；可点「放大」看条形明细。
- **销售**：行内展示该客户本年各销售及下单预估金额（**按金额降序**）；≤3 人全写，>3 人前三 +「另有 N 人」（悬停可看全）；**不再**使用「主销售」说法。
- **静默**：近 2 个**已过去完整自然月**下单预估为 0（**当前月不计入**）；故当月有单仍可能静默；年累计仍可很大。面板顶部有说明；名单旁有「静默」角标。
- **折线**：1～12 月连续下单；高亮当前相关月（顶栏若选到具体月则高亮该月，否则系统月）；**不因切月重算等级**。
- **日查**：「按时间段查询」只换上方排名，**不**改本块名单、等级与连续月图。
- **业务线页**：只看本业务线销售名下客户，不串线。

## 3. 换时间段

- 顶栏点当前周期，弹出 **年 / 季 / 月 / 自定义区间** 两段式选择（月份多时也不会被下面卡片挡住）。自定义区间用 **起月—止月 + 应用** 按时间筛选，没有 1-2 月、2-3 月那种快捷组合墙。
- 切换后，五张卡和利润表数字会跟着变；**页面不应整页乱跳**。
- 若做了「按时间段查询」，排名卡会标出查询区间；可用 **本月** 快捷到当月 1 日～今天。
- 右上角 **浅色/深色** 一切即换（图表与管理端内容同步，不必刷新整页）。

---

## 4. 业务线（BU）页

- 顶栏或 BU 分页可进某条业务线。
- 只显示该业务线的数字，**看不到其他业务线的客户/人员**。
- 若账号有**整体**权限，业务线页可点 **← 整体** 回到全公司；纯业务线账号不会显示该按钮。

## 5. 手机

- 用手机浏览器打开同一地址即可（建议公司 Wi‑Fi）。
- 窄屏时卡片会竖着排；功能与电脑相同，操作面积更紧。

## 6. 退出

- 点右上角 **退出**。
- 退出后再刷新，需要重新登录。

## 工资大类说明（全端）

**工资不在看板单独成行**：各端费用图、利润表、明细默认视图中，原「工资」大类金额**并入「其他」**显示（敏感口径，明昊拍板）。  
对账时若台账有「工资」行而看板「其他」偏大，属预期；管理端数据调整仍可查原始分类（隐工资策略同见铁律）。
